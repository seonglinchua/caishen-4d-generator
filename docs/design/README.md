# Design archive

`archive/` preserves experiments that are not used by the website:

- `caishen-refined-master.png` and `caishen-refined.webp`: opaque mascot artwork rejected because its background remained visible.
- `icon-192.png` and `icon-512.png`: cream-backed face icons reserved for a possible future web manifest.

The active mascot is `assets/images/caishen.png`. Browser icons are transparent; the Apple touch icon is cream-backed. Deploy only the root entry point, favicon, and `assets/`; design archives are not needed at runtime.
